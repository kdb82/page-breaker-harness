# Browser game

## summary
I want to create a chrome extension that allows me to control a pixelated stick figure that has access to various weapons. This soldier should be able to jump on platform on the various text, images and other elements of the webpage I activate the extension on. Shooting the weapons this figure has should destroy the various elements of the webpage. 

## basic movement
the stickman should have access to basic 'wasd' controls. W should be the jump button, 'a' move left and 'd' move right. 's' should be crouch. 

## weapons
The stick figure should have access to 4 main weapons:
- a pistol
- an AR
- a rocket launcher
- a laser. 

These weapons should all have their own sounds and particle effects. The stickman should aim and shoot where the user has their mouse and shoot in the location they click. Explosions should leave holes in the web page. 

## scoring
The user should get a score based off of the amount of destruction they cause. Each weapon should have limited ammo capacity. Ammo pickups should periodically spawn somewhere on the screen to refill. Larger weapons with greater destruction ceiling should have less ammo.

## dev rules
Do not use any assets or API's that cost money.
